# Testimonial Block

## Project Description

For my project, I plan to create a custom WordPress Gutenberg block that allows users to display customer testimonials on their websites. The block will provide a simple way to showcase customer feedback in a clean and organized layout without having to write code.

I chose this project because testimonials are commonly used on business websites, and I want to learn more about creating custom blocks and working with the WordPress editor.

## Planned Features

The block will include the following features:

- Allow users to enter a customer's name.
- Add and edit testimonial text.
- Include an optional customer profile image.
- Display a star rating from one to five.
- Provide basic customization options for background and text colors.
- Display the testimonial in a clean, responsive card layout.

## Technologies

The project will use the following technologies:

- **WordPress:** The content management system used to run the website.
- **Gutenberg:** The WordPress block editor used to create and edit the testimonial block.
- **HTML:** Used to structure the block's content.
- **CSS:** Used to style the testimonial card and make it responsive.
- **JavaScript:** Used to handle block functionality and editor interactions.
- **PHP:** Used to register the custom block with WordPress.

## Development Plan

I plan to work on the project in the following stages:

1. Set up the basic WordPress block structure.
2. Register the block and create its initial layout.
3. Add editable fields for the customer's name and testimonial.
4. Add the optional profile image and star rating.
5. Add basic styling and customization options.
6. Test the block in the WordPress editor and make improvements.

## Learning Goals

Through this project, I hope to improve my understanding of WordPress development, especially creating custom Gutenberg blocks. I also want to gain more experience working with JavaScript, PHP, HTML, and CSS while learning how these technologies work together in WordPress.

## Future Improvements

If time allows, I would like to add additional layout options and more customization features so users can adjust the appearance of their testimonial cards.
